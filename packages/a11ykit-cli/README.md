# a11ykit

> 🛠️ **15 Free, 100% Client-Side Web Accessibility Tools for WCAG 2.2 and EAA Compliance.**  
> 🌐 **Official Web App**: [https://a11ykit.site](https://a11ykit.site)  
> 🏷️ **GitHub**: [https://github.com/gstar-byte/a11ykit](https://github.com/gstar-byte/a11ykit)

---

## ⚡ Instant CLI Quickstart

Run directly without installing via `npx`:

```bash
# Check color contrast between two hex colors
npx a11ykit contrast "#2563eb" "#ffffff"

# List all 15 free web tools
npx a11ykit list
```
